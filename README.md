# ASPECT: Deep Heuristic Audit & DDE Engine
**Clinical-Grade Cognitive Telemetry for the Singapore-Batam Digital Corridor.**

## 🚀 Overview
ASPECT is a forensic logic engine designed to audit the "Heuristic Crack" in student decision-making. Unlike traditional assessment tools that only record final answers, ASPECT utilizes **1ms Edge Telemetry** to map the "Time of Flight" across three critical cognitive nodes: **Discovery, Declaration, and Execution.**

## 🛠 The DDE Framework
The engine isolates cognitive labor into three distinct phases to identify specific logic failures:

1. **Discovery (Semantic):** Time taken to process the prompt and identify key variables.
2. **Declaration (Spatial/Logic):** The "Cognitive Transition" where the student maps relationships between variables.
3. **Execution (Calculation):** The final arithmetic output phase.

## 📡 Technical Moat
- **Precision:** 1ms resolution timestamping using Python's epoch-differential logic.
- **Architecture:** Built for Hybrid-Edge deployment (Singapore-Batam Corridor).
- **Audit logic:** Dynamic thresholding (Min/Max ms) based on Singapore MOE Scholar Benchmarks.

## 📊 Live MVP
The current MVP is built in **Streamlit** and simulates a fuel-efficiency logic challenge. It provides real-time diagnostic feedback such as:
- **Guessing:** Sub-threshold performance.
- **Cognitive Stalling:** Significant logic-path latency.
- **Logic Lag:** Semantic processing overload.
